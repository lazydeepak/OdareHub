# Shell Style

Placeholder home for future Shell-owned style sockets and runtime style consumption helpers.

This structure is inert. Nothing here is autoloaded, required, routed, rendered, or consumed yet.

## Ownership

- Shell owns style sockets and future runtime consumption.
- Shell does not own style decisions.
- Platform/System owns approved active/default style registry truth.
- Customization Studio edits drafts/previews only.
- Apps/modules own scoped CSS and consume shared sockets.
- Organization owns brand identity.
- `public/assets` is generated delivery output only.

## Slice Boundary

No runtime behavior, Shell UI redesign, CSS rewrite, URL surface registration, Core change, Customization Studio connection, Studio draft read, ThemeTool change, or `public/assets` source edit is introduced by this placeholder structure.
