# Discussion Notes

This folder preserves useful project discussion before it becomes official architecture law, an active task brief, or implementation work.

Discussion notes are allowed to contain tentative ideas, open questions, and remembered chat context. They are not authority for code changes by themselves.

## Use This Folder For

- planning conversations that should not be lost
- unofficial decisions that need review before implementation
- product-shape notes for future apps or modules
- questions that must be resolved before an active task starts

## Do Not Use This Folder For

- mandatory engineering rules
- completed implementation evidence
- long raw chat transcripts
- generic memory dumps
- source-of-truth architecture contracts

## Graduation Paths

- Current project state goes to `docs/CURRENT.md`.
- Live implementation context goes to `docs/active/<task>.md`.
- Future queued work goes to `docs/BACKLOG.md`.
- Official architecture contracts go to `docs/architecture/`.
- Owner-specific durable decisions go to `engineering/<owner>/decisions.md`.

Each note should clearly mark which parts are confirmed, tentative, and still open.
