# ERP App Studio Template Manifest Contract

Schema: `studio.template-manifest.v1`

Status: registry placeholder only

Defines non-executing templates available to Studio drafts.

Required sections:

- `template.template_key`
- `template.display_name`
- `template.category`
- `template.description`
- `template.outputs`
- `guardrails`

Template categories in the foundation registry:

- Business App
- System App
- CRUD Module
- Dashboard Module
- Queue/Workflow Module
- Table View
- Form View
- Detail View
- Navigation Entry
