# ERP App Studio Positioning

Status: Placeholder direction only

ERP App Studio is the governed authoring layer for Susankhya OS apps and modules. It replaces user-facing GUI Studio language while preserving current technical route and key names during this phase.

## Future Registry Areas

- Templates: reusable app and module starting points.
- Manifests: app-owned declarations for navigation, routes, widgets, permissions, lifecycle, and dependencies.
- Artifact generation: generated files, previews, validations, and migration plans.
- Publish governance: review, approval, compatibility checks, packaging, rollback planning, and audit history.

## Non-Goals For This Phase

- No publish implementation.
- No route rename.
- No folder or namespace rename.
- No generated artifact contract enforcement beyond documentation.
