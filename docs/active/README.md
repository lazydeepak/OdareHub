# Active Task Briefs

Use this folder for live task context that should be read by agents working on an active implementation slice.

Each active task brief should include:

- objective
- owner and source areas
- relevant requirements
- boundaries and non-goals
- implementation notes
- validation plan
- current status
- handoff notes

When a task is complete, move durable decisions to the relevant `decisions.md`, update owner `work.md`, and leave only useful historical evidence in the appropriate docs area. Do not let completed task briefs become generic memory.
